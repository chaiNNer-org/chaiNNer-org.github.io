chaiNNer is now public. You can find the release on GitHub.

It's a flowchart and node-based image processing GUI, aimed at making it easy, intuitive, and customizable to chain image processing tasks together — especially the ones done by neural networks.

## Update 1

Thanks for the interest. Just a reminder that this is still pretty early in development, so expect there to be issues. Specifically, if it seems to be stuck loading on the splash screen, which is a common problem, let me know as soon as possible.

## Update 2

Thanks everyone for a good launch day. As I anticipated, a few issues popped up early on, but luckily the major ones are fixed now and I have plans to fix the others. I'm thankful for all the kind words I've received so far, and I can't wait to continue adding more to chaiNNer 🙂
