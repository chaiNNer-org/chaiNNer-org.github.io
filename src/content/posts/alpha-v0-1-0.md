chaiNNer is now public! You can find the release on GitHub.

A flowchart/node-based image processing GUI aimed at making chaining image processing tasks (especially those done by neural networks) easy, intuitive, and customizable.

## Update 1

Thanks for the interest in chaiNNer! Just a reminder that this is still pretty early in development so expect there to be issues. Specifically if it seems to be stuck loading on the splash screen (a common problem) let me know ASAP.

## Update 2

Thanks everyone for a good launch day! As I anticipated, a few issues popped up early on but luckily the major ones are fixed now and I have plans to fix the others. I'm thankful for all the kind words I've received so far and I can't wait to continue adding more to chaiNNer 🙂
