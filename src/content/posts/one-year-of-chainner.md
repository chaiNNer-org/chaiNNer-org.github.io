Hey everyone! Today is the 1-year anniversary of chaiNNer's first public release! 🥳🎉

I wanted to use this as an opportunity to thank everyone here for the continued support, and for all the great feedback, suggestions, and feature ideas we've been given. Many of the things that currently make chaiNNer great were based on community feedback, and I love that we're able to have this kind of dynamic with our users. It's also great to see chaiNNer being used for all sorts of different tasks I never envisioned would be possible with it.

I also wanted to take this opportunity to let you all know of a couple upcoming things, in regard to chaiNNer and just in general.

Firstly, I want to start off by listing a couple major features we plan on finishing at some point this year:

- CLI Mode (running chains from the command-line)
- Iterator rewrite (in-line iteration rather than separate nodes)
- Plugin system (allowing third-party nodes)
- Built-in templates
- User-made presets

And plenty more.

Secondly, I'd like to announce that we now have an actual website for chaiNNer: https://chainner.app/. The site isn't anywhere close to being finished (I whipped it together in 2 days, and it completely breaks on mobile), but it's a good starting point for a secondary resource for downloading chaiNNer and seeing information somewhere other than the GitHub page or the Discord. If you have any suggestions for things to include on this site (eventually), do let us know! Alongside the current download links and changelog, I plan on hosting troubleshooting information, a how-to guide, and various helpful resources.

Lastly, at some point this year, we will probably be taking a slight break from working on chaiNNer to work on a new model database. We don't have any concrete details about it at the moment, but basically we decided it would be extremely beneficial to have a dedicated resource for finding models that isn't just a wiki page. This should end up indirectly benefitting chaiNNer, since right now it is pretty difficult to find models (and new users always ask where to find them, which to use, etc). I'll give more updates on this when we actually start to prioritize it.

Also, you might notice there's been a slight change here in the Discord — #announcements is now #releases, and I will be using this channel (#announcements) for non-release related announcements going forward.

That's all. Thanks again, and Happy Birthday chaiNNer! 🥳🎉
